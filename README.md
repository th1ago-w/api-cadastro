# API de Cadastro

API simples de cadastro de usuários em Python com Flask.

## Como rodar

`pip install flask`  
`python app.py`

## Endpoints

**Cadastrar usuário**  
POST `/cadastrar`  
Exemplo: `{"nome": "Thiago", "email": "thiago@email.com"}`

**Listar usuários**  
GET `/usuarios`

## Tecnologias

- Python
- Flask
